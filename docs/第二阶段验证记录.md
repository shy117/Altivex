## 集成中已处理的问题

- Windows C 盘 Pub 缓存与 E 盘工程导致 Kotlin 增量缓存报 `different roots`：项目级 `kotlin.incremental=false`，未移动文件或修改全局环境。
- 相机与相册插件对旧 Android 存储权限的 `maxSdkVersion` 声明冲突：以 `tools:replace` 明确采用相册插件要求的 API 29 上限。
- 相机插件默认声明录音权限和必需摄像头：本应用只拍照，移除录音权限并显式将摄像头标为可选。
- Android 默认融合定位会出现 Google 定位增强提示：Android 适配层改用系统 LocationManager，前台 GPS 不依赖该增强服务；iOS 继续使用系统定位。
- GPS 精度取整后可能显示 ±0 米：改为向上取整，显示最小 ±1 米；这不代表保证测量精度。
- GPS 没有有效垂直精度时不采用高度值，避免将 Android 的无高度占位值 0 显示为真实海拔。
- 定位服务恢复时先重置旧权限状态，避免初始服务事件引发重复启动。
- CameraX 在系统永久拒绝相机权限时可能持续重试：Android 在初始化前用 permission_handler 预检与请求权限；相机枚举超时 10 秒、初始化超时 15 秒，提供重试和设置入口。权限插件限定为兼容 SDK 36 的 12.x，避免引入 SDK 37 工具链升级。
- 相机预览原先额外强制竖屏比例，与插件原生横竖屏适配冲突：移除外层固定比例，将水印置于相机预览内部，按实际照片比例绘制。
- 原先取景与成片分别拼装水印内容，造成信息不同：两者统一使用 `PhotoWatermarkPainter`，短边决定相对字号，快门时冻结同一份数据快照。
- 主界面横屏仍按最小 620 高度竖排：增加左右布局并复用仪表盘组件，避免横屏必须滚动才能查看坐标。
