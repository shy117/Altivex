# 相机真机测试清单

## 本轮调整

- 设置面板按参考图分组；顶部标题固定，上划滚动内容，从顶部把手下拉可关闭。
- 白色双圈快门；顶部依次为返回、闪光灯、水印、设置。
- 16:9 竖屏取景铺满宽度，控件浮在画面上；横屏保留原设备底边的按钮位置。
- 自动保存成功不弹提示，左下角更新最新缩略图；失败仍提示且保留恢复照片。
- 四套水印均在左上角加入透明底纯白 Logo 与“Altivex 高度计”，共用取景与导出绘制逻辑。原始彩色 SVG 保留。
- 双指触摸优先锁定照片翻页，缩回原比例后单指恢复翻页；水印字号按画面短边缩放，取消高分辨率成片的固定字号上限。

## 建议按顺序验证

1. **外观与比例**：分别选择 4:3、16:9、1:1，检查两侧黑边、画面拉伸、按钮遮挡。横向左右各转一次，拍摄并在相册核对成片方向和比例。屏幕空间有限时，16:9 控件会覆盖取景画面的一部分。
2. **手动保存**：关闭自动保存，拍照进入预览；未按保存前相册不新增，保存后不重复写入；返回只有左上角，分享在右上角。
3. **自动保存**：开启后连续拍两张，不进入预览、不出现保存成功提示，左下角缩略图更新；打开记录及系统相册核对照片完整。
4. **格式与分辨率**：JPEG、PNG 各拍一张。在系统相册详情查看宽高，4:3、1×后置镜头建议优先测试；相机请求最高分辨率，不缩小导出，16:9、1:1 会裁切像素范围。不会另外保存无水印原图；处理失败仅在应用内留恢复文件。请分别记录从按快门到可操作的耗时，JPEG 使用 Android 原生编码，PNG 仍可能较慢。
5. **水印**：逐一试四套模板，检查左上白色 Logo 与文字间距、阴影、四角位置以及取景与成片的一致性；关闭水滴后导出照片完全无水印。倒计时中改变位置，水印使用实际快门时刻的数据；无定位时显示缺失值。
6. **拍摄辅助**：切换闪光灯、前后镜头和可用倍率；双指变焦，点击对焦后上下滑动调整曝光；曝光只显示太阳图标，不显示数值；点击其他位置重新对焦后曝光补偿恢复为零。九宫格和水平仪不写入成片。
7. **定时**：分别试 3 秒、10 秒；中途取消、返回或切后台，不应意外拍照或卡住。
8. **历史与删除**：进入任意历史照片后左右滑动切换，标题显示序号，保存和分享应对应当前照片；放大查看时拖动照片，缩回原比例后恢复切换。退出重开后设置和记录保留。删除不勾选时相册副本仍在，勾选后对应副本也删除，其他照片不受影响。
9. **恢复与权限**：后台再返回、拒绝相机权限后重新允许，能恢复；相册写入失败时有明确提示，记录中仍能重试。请勿通过删除个人照片或清空应用数据模拟故障。
10. **室外传感器**：检查 GPS 海拔、位置和速度；有气压计时检查气压和校准；旋转手机检查方向。断网后仍能使用设备具备的传感器；无传感器不得显示伪造数据。

## 反馈格式

记录问题时说明：手机型号、横/竖屏、照片比例、JPEG/PNG、自动保存开关、操作步骤、实际结果。界面问题提供截图；成片问题提供测试照片，注意位置隐私。

## 验证边界

已执行 40 项自动测试，含偏移双指缩放及 3000×4000 水印相对尺寸回归；33 组模拟器原生合成检查通过。Android JPEG 已改为原文件与水印小图块合成，真机单样本自动保存耗时从约 2.11 秒下降至约 1.57 秒，成片仍为 3000×4000；不是保证值，完整条件见 [拍摄性能排查记录](拍摄性能排查记录.md)。性能包 `build/altivex-camera-profile.apk` 使用预编译 Dart，不含热重载。iOS 尚未在 macOS/Xcode 构建验证。
